# D210 Representation & Reporting

## Course Summary
This course focuses on communicating observations and patterns to diverse stakeholders, a key aspect of the data analytics life cycle. This course helps students gain communication and storytelling skills. It also covers data visualizations, audio representations, and interactive dashboards. This course has one Practical Assessment.

## Course Objectives
* **Data Visualization:** The graduate creates data representations to offer insight into an organizational problem.
* **Business Intelligence:** The graduate communicates data insights to technical and nontechnical audiences.
* **Executive Dashboards:** The graduate designs executive decision support with interactive tools.

## Practical Assessment Overview
This project requires the student to use one of the two provided datasets (medical or churn) and an additional external dataset of their own choosing to generate a series of data visualizations about the two datasets. These visualizations are developed in Tableau to generate interactive dashboards with filtering capability. The student then gives a presentation of these finished dashboards to an executive board for their chosen dataset (medical or churn) with Business Intelligence and insights generated from both datasets.

For this project, I used data from the [U.S. Census](https://www.kaggle.com/datasets/muonneutrino/us-census-demographic-data), sourced from Kaggle, as my external dataset. This provided insights into state-level and economic information which would be helpful in determining customer demographics and churn behavior. My Python code can be viewed [here](https://github.com/hillaryosei/MSDA_Portfolio/blob/main/D210/d210-churn-task1.ipynb). The interactive dashboard is hosted on Tableau Public and can be viewed [here](https://public.tableau.com/app/profile/hillary.osei1583/viz/D210-Updated/D210Presentation).
